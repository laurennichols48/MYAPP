## Lab 5: The Box Model and Visual Styling

**Course focus:** typography, colors, images, width, padding, borders, margins, footers, and reusable visual classes  
**Estimated lab time:** 45–50 minutes  
**Central question:** Why can an element occupy more space than its width suggests?

### Lab Goals

By the end of this lab, students will be able to:

- Identify content, padding, border, and margin in the CSS box model.
- Predict the total space occupied by a styled element.
- Use `box-sizing: border-box` to make sizing easier to manage.
- Style fonts, colors, images, borders, spacing, and footers.
- Use consistent spacing rather than random one-off values.
- Refactor repeated card styles into a reusable class.
- Improve the visual design of a portfolio page without changing its meaning.

### Lab Activities

1. **Measure a Box**  
   Students predict and then observe how width, padding, border, and margin affect an element.

2. **Change One Layer at a Time**  
   Students isolate the visual effect of padding, border, and margin.

3. **Repair Uneven Project Cards**  
   Students fix overflow, inconsistent image sizing, and repeated declarations.

4. **Style a Footer and Type System**  
   Students add readable typography, colors, and page-level spacing.

5. **Portfolio Checkpoint**  
   Students apply a consistent box model and visual system to their own site.

### Portfolio Connection

Students leave this lab with a concrete improvement to the personal portfolio website. The checkpoint is intentionally limited so students can focus on the new concept while preserving working code from earlier labs.
