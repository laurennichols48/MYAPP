# Lab 3: Overview

## Why Do We Need CSS?

**Course focus:** Inline, internal, and external CSS; CSS rule anatomy; separation of structure and presentation; stylesheet links; and refactoring  
**Estimated lab time:** 45–50 minutes  
**Central question:** Where should styling instructions live when a website grows?

## Lab Goals

Students will be able to:

- Explain the different roles of HTML and CSS.
- Identify inline, internal, and external CSS.
- Identify selectors, properties, values, and declarations.
- Connect HTML to an external stylesheet.
- Compare the maintenance costs of three styling methods.
- Refactor repeated inline styles.
- Repair a broken stylesheet link.

## Activities

1. Compare three visually similar pages.
2. Locate the CSS in each version.
3. Change the same style in each version.
4. Count repeated inline declarations.
5. Move styles into internal and external CSS.
6. Repair a broken stylesheet connection.
