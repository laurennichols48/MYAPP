## Lab 1: Overview

**Course focus:** HTML syntax, elements, tags, attributes, nesting, and basic document structure  
**Estimated lab time:** 45–50 minutes  
**Central question:** How does a browser turn plain text into a structured webpage?

### Lab Goals

By the end of this lab, students will be able to:

- Identify the components of an HTML element.
- Explain the purpose of angle brackets and closing tags.
- Distinguish among a tag, element, attribute, attribute value, and content.
- Correctly nest HTML elements.
- Use headings, paragraphs, lists, links, and a simple image.
- Create a basic HTML document.
- Open an HTML file in a browser and inspect the result.
- Identify and repair common HTML errors.

### Lab Activities

1. **Inspect an Existing Webpage**  
   Students open a prepared HTML file in a code editor and a browser. They compare the source code with the rendered page and identify patterns in the syntax.

2. **Change, Predict, and Observe**  
   Students modify headings, paragraphs, tags, links, and nesting. Before refreshing the browser, they predict how each change will affect the page.

3. **Identify the Components of HTML**  
   Students label the opening tag, closing tag, content, attribute, attribute value, visible content, and complete element in sample HTML code.

4. **Repair Broken HTML**  
   Students correct missing closing tags, incorrect nesting, misspelled tags, missing quotation marks, broken links, and incorrectly structured lists.

5. **Create a Basic Webpage**  
   Students create an `index.html` file containing headings, paragraphs, a list, a link, and correctly nested elements.
