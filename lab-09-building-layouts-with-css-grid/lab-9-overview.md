## Lab 9: Building Layouts with CSS Grid

**Course focus:** grid containers, tracks, gaps, spanning, responsive columns, and choosing between Grid and Flexbox  
**Estimated lab time:** 45–50 minutes  
**Central question:** How can rows and columns be designed together without positioning every item separately?

### Lab Goals

By the end of this lab, students will be able to:

- Identify a grid container, grid items, rows, and columns.
- Create columns with `grid-template-columns`.
- Use `gap` to separate rows and columns.
- Span an item across multiple tracks.
- Create a responsive card grid with `repeat()`, `minmax()`, and `auto-fit`.
- Compare two-dimensional Grid layouts with one-dimensional Flexbox layouts.
- Use Grid to organize the projects or experience page of the portfolio.

### Lab Activities

1. **Build Explicit Columns**  
   Students change the number and size of grid tracks and predict the result.

2. **Place a Featured Item**  
   Students make one card span more than one column and evaluate the reading order.

3. **Create a Responsive Gallery**  
   Students use `repeat(auto-fit, minmax(...))` and resize the browser.

4. **Choose Grid or Flexbox**  
   Students classify several layout problems and justify a tool choice.

5. **Portfolio Checkpoint**  
   Students build a responsive projects or experience grid.

### Portfolio Connection

Students leave this lab with a concrete improvement to the personal portfolio website. The checkpoint is intentionally limited so students can focus on the new concept while preserving working code from earlier labs.
