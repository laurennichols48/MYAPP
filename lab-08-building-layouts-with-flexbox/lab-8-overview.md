## Lab 8: Building Layouts with Flexbox

**Course focus:** flex containers, main and cross axes, alignment, gaps, wrapping, sizing, navigation, and one-dimensional responsive layouts  
**Estimated lab time:** 45–50 minutes  
**Central question:** How can a group of items share and rearrange space along one main direction?

### Lab Goals

By the end of this lab, students will be able to:

- Identify the flex container and flex items.
- Distinguish the main axis from the cross axis.
- Use `justify-content`, `align-items`, and `gap`.
- Change layout direction with `flex-direction`.
- Allow items to move to another line with `flex-wrap`.
- Use flexible sizing without assigning fixed positions.
- Build a responsive navigation bar and aligned content row.

### Lab Activities

1. **Map the Axes**  
   Students change `flex-direction` and predict which alignment property controls each direction.

2. **Align Navigation Items**  
   Students build a horizontal navigation bar with spacing and vertical alignment.

3. **Make Cards Wrap**  
   Students replace fixed widths with flexible sizing and test a narrow viewport.

4. **Repair a Flex Layout**  
   Students correct styles applied to the wrong element and remove unnecessary positioning.

5. **Portfolio Checkpoint**  
   Students use Flexbox for navigation and at least one one-dimensional content group.

### Portfolio Connection

Students leave this lab with a concrete improvement to the personal portfolio website. The checkpoint is intentionally limited so students can focus on the new concept while preserving working code from earlier labs.
