# Portfolio Mockup Checklist

- [ ] The page goal is clear.
- [ ] The first focal point matches the main priority.
- [ ] Navigation is easy to locate.
- [ ] Related content is grouped.
- [ ] Major edges align.
- [ ] Repeated elements use consistent treatment.
- [ ] Whitespace separates groups.
- [ ] Desktop and mobile frames contain the same essential content.
- [ ] Mobile sections stack or simplify intentionally.
- [ ] Links and controls are visually recognizable.
- [ ] The design can be built with the course tools.
- [ ] Realistic content lengths are represented.
