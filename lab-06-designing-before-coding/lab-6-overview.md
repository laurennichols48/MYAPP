## Lab 6: Designing Before Coding

**Course focus:** visual hierarchy, contrast, alignment, repetition, spacing, content planning, accessibility, and Figma mockups  
**Estimated lab time:** 45–50 minutes  
**Central question:** What decisions should be made before writing layout code?

**Instructor note:** This lab intentionally appears before the positioning, Flexbox, Grid, and Bootstrap labs so students plan hierarchy and responsive structure before implementing more complex layouts. Instructors may preview content inventory or lightweight wireframing earlier in the course, but the full mockup activity is designed to occur here.

### Lab Goals

By the end of this lab, students will be able to:

- Identify visual hierarchy, contrast, alignment, repetition, and whitespace.
- Explain why a design can be attractive but still difficult to use.
- Evaluate a page using usability and accessibility criteria.
- Create a content inventory for a portfolio website.
- Sketch a low-fidelity page structure before choosing visual details.
- Create a simple desktop and mobile mockup in Figma.
- Use the mockup as a plan rather than treating it as an unchangeable final design.

### Lab Activities

1. **Compare Two Websites**  
   Students evaluate an intentionally ineffective page and a clearer redesign.

2. **Prioritize the Content**  
   Students decide what a visitor should notice first, second, and third.

3. **Create a Content Inventory**  
   Students list the text, links, images, and sections needed on each portfolio page.

4. **Build a Low-Fidelity Figma Mockup**  
   Students create simple desktop and mobile frames using boxes and text.

5. **Peer Design Check**  
   Students exchange mockups and give feedback tied to concrete design principles.

### Portfolio Connection

Students leave this lab with a concrete improvement to the personal portfolio website. The checkpoint is intentionally limited so students can focus on the new concept while preserving working code from earlier labs.
