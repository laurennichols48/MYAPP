## Designing Before Coding

## Plan Your Portfolio Before Layout

You have already built and styled the basic structure of your portfolio in Labs 2–5. Before you begin the layout-focused work in Labs 7–10, use this lab to step away from code and make deliberate decisions about visual hierarchy, content organization, and responsive design.

Your finished portfolio should include:

- A homepage, an About page, and a projects, interests, or experience page.
- Working navigation between every page.
- Descriptive links and meaningful image alternative text.
- Thoughtful use of classes and IDs, with correctly nested HTML.
- A visually coherent, intentional design.

This lab comes before the layout-focused labs for a reason: the decisions you make here — what a visitor should notice first, how content is organized, and what the site should look like on a phone — are far cheaper to make in a mockup than to redo after implementing a complex layout.

### Guiding Question

What decisions should be made before writing layout code?

### Lab Goals

After completing this lab, you will be able to:

- Evaluate visual hierarchy, contrast, alignment, repetition, and whitespace.
- Identify usability and accessibility problems in a design.
- Decide what a visitor should notice first.
- Inventory the content required on each portfolio page.
- Create desktop and mobile mockups in Figma.
- Give feedback using specific design principles.

## Before You Begin: What Is Visual Hierarchy?

Visual hierarchy is the order your eye is drawn to things. Think of a restaurant menu, a street sign, or a movie poster: some things you notice instantly, others take a second look, and a few you'd only find if you went looking for them. That's not an accident — someone designed it that way.

## Part 4: Create a Low-Fidelity Figma Mockup

Open Figma and create a new design file.

### Desktop Frame

1. Add a desktop-sized frame.
2. Use plain rectangles for major regions.
3. Add text labels for the header, navigation, main sections, and footer.
4. Show approximate spacing and alignment.
5. Add only enough text to show hierarchy.

### Mobile Frame

1. Duplicate the design into a narrow frame.
2. Decide how navigation will fit.
3. Stack or simplify sections that no longer fit side by side.
4. Preserve the same content priorities.
5. Check that text and controls are not crowded.

Low fidelity means:

- No need for final images.
- No need for perfect colors.
- No need for detailed icons.
- Focus on structure, order, and space.

The supplied wireframe SVG can be used as a reference.
