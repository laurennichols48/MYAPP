# Lab 2: Overview

## Organizing and Connecting Webpages

**Course focus:** Semantic HTML, `<div>` elements, heading hierarchy, relative links, navigation, introductory accessibility, and inline CSS  
**Estimated lab time:** 45–50 minutes  
**Central question:** How can we organize webpage content so that people and browsers understand it?

## Lab Goals

Students will be able to:

- Organize content with `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
- Explain the difference between a semantic element and a generic `<div>`.
- Use headings to communicate page structure.
- Connect two HTML files using relative links.
- Create a simple navigation menu.
- Use descriptive link text.
- Add simple inline CSS with the `style` attribute.

## Activities

1. Inspect an organized webpage.
2. Match content with appropriate semantic elements.
3. Repair broken navigation links.
4. Connect a home page and an about page.
5. improve page titles, heading order, and link text.
6. Add introductory inline styling and identify its limitations.
