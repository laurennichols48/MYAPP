## Lab 7: Positioning and Page Flow

**Course focus:** block and inline flow, static, relative, absolute, fixed positioning, and limited image floats  
**Estimated lab time:** 45–50 minutes  
**Central question:** When should an element stay in normal page flow, and when should it be positioned?

### Lab Goals

By the end of this lab, students will be able to:

- Distinguish block and inline formatting behavior.
- Explain normal document flow and `position: static`.
- Use `position: relative` as a local positioning reference.
- Place a small overlay with `position: absolute`.
- Use fixed positioning only for a deliberate viewport-level element.
- Use a float for a limited text-wrapping example and clear it correctly.
- Recognize why absolute positioning is usually a poor tool for an entire page layout.

### Lab Activities

1. **Observe Normal Flow**  
   Students change elements between block and inline display and record how neighboring content moves.

2. **Test Position Values**  
   Students apply static, relative, absolute, and fixed positioning one at a time.

3. **Repair an Escaping Badge**  
   Students correct an absolutely positioned label that uses the wrong containing block.

4. **Wrap Text Around an Image**  
   Students test a limited float and prevent later content from wrapping unexpectedly.

5. **Portfolio Checkpoint**  
   Students add one purposeful positioned detail without using positioning for the main layout.

### Portfolio Connection

Students leave this lab with a concrete improvement to the personal portfolio website. The checkpoint is intentionally limited so students can focus on the new concept while preserving working code from earlier labs.
