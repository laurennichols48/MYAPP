## Lab 10: Bootstrap and Responsive Website Build

**Course focus:** Bootstrap 5.3, containers, responsive grid classes, components, utilities, customization, and final portfolio integration  
**Estimated lab time:** 45–50 minutes  
**Central question:** How can a framework speed up development without making every website look identical?

### Lab Goals

By the end of this lab, students will be able to:

- Explain what a CSS framework provides and what it does not decide.
- Connect a page to Bootstrap using the supplied CDN links.
- Use containers, rows, columns, breakpoints, components, and utilities.
- Read responsive class names such as `col-12 col-md-6`.
- Customize Bootstrap with a separate stylesheet loaded after the framework.
- Test a multi-page site at narrow and wide viewport sizes.
- Complete and review the personal portfolio website.

### Lab Activities

1. **Decode Bootstrap Classes**  
   Students inspect a component page and infer what common utility and grid classes do.

2. **Build a Responsive Section**  
   Students create columns that stack on smaller screens and sit side by side on larger screens.

3. **Customize a Component**  
   Students change typography, colors, spacing, and card treatment using `custom.css`.

4. **Complete the Multi-Page Site**  
   Students finish the supplied portfolio starter or transfer Bootstrap patterns into their existing site.

5. **Responsive and Accessibility Review**  
   Students test navigation, links, headings, alternative text, and layout at multiple widths.

### Portfolio Connection

Students leave this lab with a concrete improvement to the personal portfolio website. The checkpoint is intentionally limited so students can focus on the new concept while preserving working code from earlier labs.
