# Portfolio Review Checklist

## Structure and Content

- [ ] The homepage, About page, and Projects/Interests/Experience page exist.
- [ ] Each page has a unique, descriptive browser title.
- [ ] Each page has one clear main heading.
- [ ] Heading levels communicate structure.
- [ ] Navigation reaches every required page.
- [ ] Content is the student’s own and is complete enough to evaluate.

## Accessibility

- [ ] The `lang` attribute is correct.
- [ ] Link text describes its destination or action.
- [ ] Meaningful images have useful alternative text.
- [ ] Decorative images use empty alternative text.
- [ ] Text and controls have readable contrast.
- [ ] Keyboard focus is visible.
- [ ] Interactive elements can be reached and used by keyboard.
- [ ] Information is not communicated by color alone.

## CSS and Layout

- [ ] Shared styles are reusable.
- [ ] Classes are used consistently.
- [ ] IDs are unique and purposeful.
- [ ] Images resize without distortion.
- [ ] The layout works at narrow, medium, and wide widths.
- [ ] No main page region depends on absolute positioning.
- [ ] Flexbox or Grid is used where it solves a real layout problem.
- [ ] Custom styles make the design distinct from the starter.

## Responsive Testing

- [ ] Navigation remains usable.
- [ ] No horizontal page scrolling is required for normal content.
- [ ] Cards stack or reorganize clearly.
- [ ] Text does not overlap or escape containers.
- [ ] The site remains usable at 200% browser zoom.
- [ ] All pages remain visually consistent.
